# Home Assistant Add-on: Actual Budget

Actual Budget is a local-first personal finance app available directly in Home Assistant.

## How to use

1. Install the add-on.
2. (Optional) Set `timezone` in add-on configuration, for example `Europe/Warsaw`.
3. Start the add-on.
4. Open Actual Budget from the add-on page using **Open Web UI**.
5. On first launch, create a new budget file or import an existing one.

## Notes

- The add-on uses ingress by default.
- Budget data is stored in the addon_config directory and persists across restarts and updates.
