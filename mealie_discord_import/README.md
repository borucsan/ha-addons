This add-on runs [mealie-discord-import](https://github.com/borucsan/mealie-discord-import) using the published image `ghcr.io/borucsan/mealie-discord-import:sha-2f352bc`, so you can import recipes into Mealie from Discord.

## Installation

Add the [repository](https://github.com/borucsan/ha-addons) in Home Assistant → **Settings** → **Add-ons** → **Add-on store** → **Repositories**, then install **Mealie Discord Import** and configure tokens in the add-on options.

Upstream documentation: [borucsan/mealie-discord-import](https://github.com/borucsan/mealie-discord-import).
