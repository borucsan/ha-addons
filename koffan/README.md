## About

[Koffan](https://github.com/PanSalut/Koffan) is a lightweight (~2.5 MB RAM idle) self-hosted shopping list application backed by SQLite with real-time WebSocket updates. Designed for families and shared households.

## Installation

1. Add this repository to your Home Assistant add-on store.
2. Install the **Koffan** add-on.
3. Start the add-on. Authentication is handled by Home Assistant ingress.
